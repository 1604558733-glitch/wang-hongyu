# 四组质量验收标准（满分100；≥95合格）

**执行原则**：每轮提交保留评审证据；顺序通过，不得跳关；存在严重安全/隐私/功能阻断问题时，即使总分≥95也判定不通过。记录每项分数、证据链接、缺陷与修复提交。

## 1 专业编程组
- 功能完整与交易闭环：25
- 测试覆盖与回归：25
- 安全和权限基础：20
- 数据持久化与部署可维护性：15
- 手机页面性能、错误处理：15

## 2 专业审核组
- 身份认证和越权防护：25
- 个人信息、隐私与数据删除：25
- 举报、内容治理与记录：20
- 上传内容和滥用防护：15
- 政策文本与发布审核准备：15

## 3 专业运营组
- 买卖双方核心任务完成率：25
- 小区发现和有效商品供给：25
- 获客与留存可行性：20
- 服务成本与风险处理：15
- 运营指标和管理可执行性：15

缺真实运营数据的维度标记「待验证」，**不能仅凭模拟评估打95分**。

## 4 真实用户组
- 找小区及找商品：20
- 手机拍照/语音发布：25
- 与卖家联系及成交路径：20
- 视觉舒适度与无障碍：20
- 稳定性与错误反馈：15

必须本人或真实用户实际在手机上测试并评分；AI 不得代替用户评分。

## 返工循环
问题登记 → 明确严重度及复现步骤 → 提交修复 → CI 回归 → 依顺序复评 → 满足≥95及零阻断缺陷后进入下一关。
